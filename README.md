# 🎵 Site Vitrine — MAZETTE

Site vitrine pour le compositeur et beatmaker **Mazette**, développé en HTML, CSS et JavaScript vanilla dans le cadre de mon projet d'alternance à **2I Academy** (formation Développement Web).

🔗 **[Voir le site en ligne](https://leonie-ctrlz.github.io/site-mazette)**

---

## 📋 Présentation

MAZETTE est un producteur français basé à Tours, dont la musique se situe à la croisée de l'electronica, du trip-hop et du beatmaking. Ce site vitrine présente son univers, sa discographie, sa galerie presse et ses dates de concert.

---

## ✨ Fonctionnalités

- **Lecteur audio custom** — lecteur 8 pistes de l'EP *A New Era* avec barre de progression, navigation entre les pistes et tracklist interactive
- **Galerie photos** avec lightbox (navigation clavier + souris)
- **Grille discographie** avec liens vers Bandcamp
- **Vidéos intégrées** — YouTube + vidéo locale
- **Timeline des dates de concert**
- **Formulaire de contact** fonctionnel via Formspree
- **Liens réseaux sociaux** (Instagram, Facebook, SoundCloud, Bandcamp, Spotify)
- **Animations au scroll** via IntersectionObserver
- **Design responsive** — adapté mobile et desktop

---

## 🛠️ Technologies utilisées

| Technologie | Usage |
|---|---|
| HTML5 | Structure sémantique |
| CSS3 | Design, animations, responsive (media queries) |
| JavaScript vanilla | Lecteur audio, lightbox, animations scroll, formulaire |
| Google Fonts | Cormorant Garamond + Inter |
| Formspree | Backend formulaire de contact |
| Git / GitHub Pages | Versioning et hébergement |

## 🎨 Choix de design

- **Palette** : noir profond `#0a0a0a`, blanc cassé `#e8e4dc`, or `#c9a84c`
- **Typographie** : Cormorant Garamond (titres) + Inter (corps)
- **Ambiance** : cinématographique et sombre, en cohérence avec l'univers musical de Mazette

## 🚀 Lancer le projet en local

```bash
git clone https://github.com/Leonie-ctrlz/site-mazette.git
cd site-mazette
```

Ouvrir `index.html` avec **Live Server** dans VS Code.
